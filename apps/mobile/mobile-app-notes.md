# HomeHunter Mobile App Notes

The active app is built directly in this repository.

Current direction:

- Mobile-first app shell in `apps/web`.
- Bottom toolbar as the primary mobile navigation.
- Desktop sidebar only for wider screens.
- Screens map to the product workflow: overview, search profiles, listings, applications, portal accounts, setup, settings and app events.

Important rule: never send an application automatically. Approval only marks a listing as ready to send.
